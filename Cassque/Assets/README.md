# Cassque assets

`Cassowary.png` is the 256-pixel picture Cassque's About box shows. It is
`Resources/Icons/Casso-0-silhouette.png`, the silhouette Casso already ships as
its default application icon, scaled down from 1024 pixels. It carries whatever
terms that icon carries in this repository.

That silhouette was traced from the photographs under `Assets/Icon/Source/` by
`Assets/Icon/build_icons.py`. The tree records no source or license for those
photographs, so this picture inherits that gap rather than closing it.

Cassque's application icon is `Resources/Icons/Casso-4-silhouette-accent.ico`,
referenced in place from `Cassque.rc` rather than copied.
