# CassetteRecorder

The Panasonic RQ-309DS portable cassette recorder (1974), drawn beside the
drive stack in the 3D desk scene on machines with cassette jacks (Apple ][,
][+ and //e).

Generated by `scripts/modelgen/cad_rq309ds.py`; regenerate there and copy
`CassetteRecorder.mesh` and `CassetteRecorder.mtl` here. Model space is
millimeters, X right, Y back, Z up, with the key end at y = 0 facing the
viewer.
