## Rules for every task

- **New files**: a task that creates a source or test file adds it to its
  project (`CassoEmuCore/CassoEmuCore.vcxproj`, `UnitTest/UnitTest.vcxproj` or
  `ScenarioTests/ScenarioTests.vcxproj`) in that same task, before the run that
  must fail. A test file outside the project never compiles and is simply
  absent from the count. This repo has no `.filters` files; if a project gains
  one, the same task registers the file there as well.
- **Style**: run `scripts/CheckStyle.ps1 -Mode Staged` before every commit.
- **Ownership check placement**: `ASSERT_THREAD_OWNERSHIP` is the first
  statement after the function's declaration block (after the three blank
  lines CS0016 requires), or the first statement of an inline one-liner's
  body. Its argument is a member, a dereference or a hoisted local reference,
  never a call. It never goes in a destructor.
- **Ownership on new members**: a task that adds a public instance member to
  `DiskImageStore` or `Disk2Controller` gives it `ASSERT_THREAD_OWNERSHIP`
  (unless R5 exempts it) and adds its row to `EveryStoreEntryPointAssertsOffItsOwner`
  or `EveryControllerEntryPointAssertsOffItsOwner` in
  `UnitTest/EmuTests/DiskOwnershipTests.cpp` in that same task, and a task that
  changes a guarded signature updates its row. The members this list adds are
  `Disk2Controller::SetThreadOwnership` (T014, whose own check, that the
  current and the new token are both held by the calling thread, takes the
  place of the macro), `GetBayStatus`, `GetStatusGeneration`, `MarkStatusChanged`,
  `SetUserWriteProtectFlag` and `SetFileWriteProtect` (T026), the `const`
  `GetEngine` overload (T027), `SetFileBacked` (T087, as a stub that T095
  fills), `AreAllWritesSaved` (T095) and `SetUserWriteProtect` (T092, as a stub
  that T104 fills); `SalvageToFile`'s row changes in T019. Public members a
  merge of 035 brings before T013 go into T013's guarded list and T012's rows:
  T008 brings `IsRetainingMedia` and `ReportSeatedMedia`.
- **Design snippets**: the code in research.md and audit.md is design, not code
  to paste. Every EHM macro condition gets its call hoisted into a descriptive
  `bool` local first (CS0011), and no local is called `ok`.
- **Long functions**: a task never adds logic to a function already over 100
  lines, or to one the addition would take over 100. These are every function
  over 100 lines that a task edits, comment-only edits included, measured in

## Merge procedure (035)

Each phase ends with a merge task. When `035-debugger` has commits this branch
lacks, merge it (never `master`) and then:

1. Build Debug and Release and fix every stale call site; renames merge cleanly
   and then fail to compile (CLAUDE.md, Hazards).
2. Re-run the full Debug suite and, once the tasks that write them have passed,
   `DiskOwnershipTests`' entry-point sweeps (T012) and `DriveStatusPublisherTests`'
   `EveryBayWriterMovesTheGeneration` (T028). T008 runs before either exists.
3. Search 035's new code for writers of an `Entry` field (`path`, `mounted`,
   `format`, `salvageOffered`, `image`) or of an image's write-protect flags,
   each of which needs a status generation bump, and for new public
   `DiskImageStore` or `Disk2Controller` members, each of which needs the
   ownership check and a sweep row. The members this branch adds get theirs
   from the task that adds them (Rules for every task). A member that arrives
   before T013 goes into T013's guarded list (or R5's exemptions) and into
   T012's row count.
4. Search for new callers of `GetDiskStore()` or `Disk2Controller` members on
   window-thread paths, and add each to the Ownership move list with the task
   that moves it and its proof. Search as well for any new thread that builds
   or replays a machine with a disk store (035's `ScratchCallReplayer` is one),
   and give it the claim and release brackets T015 gives the scratch machines.
5. Once T051 has passed, repeat T051's Debug app run.
6. Measure the merged 035 commit's own Debug and Release test counts and add a
   Baselines row.

When there is nothing to merge, the task records that.
